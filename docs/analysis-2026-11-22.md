# Emacs configuration analysis, 2026-11-22

Produced by an Opus 5.5 subagent (read-only; tests ran on a copy with a throwaway HOME). Emacs version: 31.1.
The agent reproduced its findings, but they were not all re-verified individually. Implementation status is at the end.

Already done before this analysis (git log, 14/15 Nov): nerd-icons instead of all-the-icons, pulsar instead of beacon, apheleia instead of blacken/prettier-js, helm-flycheck removed, Elixir layer disabled, smartparens hooks deduplicated, backup directories moved, reload function repaired, a missing ESLint no longer aborts the JS hooks, theme follows Omarchy, `install.sh` and docs.

## Verdict

The structure is tidy and well commented (modular, `use-package`, documented), but it is still written for Emacs 27/28. Five real defects:

1. **apheleia was not installed.** The package index in `elpa/archives` dated from 18 Oct, so the download failed with "Not found". Mode hooks for Python/JS/HTML probably aborted. pulsar was missing too.
2. **Opening `requirements.txt` raised `void-variable ac-modes`.** The hook `pip-requirements-auto-complete-setup` needs auto-complete, which is not installed.
3. **`tab-width` was 2 globally and `indent-tabs-mode` off globally.** Cause: the `setq-default` in the `:init` of js2-mode.
4. **lsp-mode and org loaded at startup** (a lambda in `:hook` for lsp-pyright, and org-modern pulled org in).
5. **`lsp-rust-analyzer-server-display-inlay-hints` no longer exists**, so Rust inlay hints were off.

Further facts:

- Batch startup time: 2.0 s (3 measurements); 1.65 s with the two lazy-loading fixes; an estimated under 1.4 s with org-modern on a hook.
- There was no `early-init.el`: no GC tuning, and the menu/tool bar flickered.
- Emacs 31.1 has Tree-sitter, but no grammars are installed and the config only uses the classic modes.
- Tools missing on tatooine: `ag`, `gopls`, `rust-analyzer`, `pyright`, `black`, `prettier`, `golangci-lint`, `eslint`, `terraform-ls`. Present: `rg`, `cmake`, `libtool`, `claude`.
- `themes/omarchy-theme.el` is missing, so the theme is not loaded ("No omarchy-theme.el found"); probably `omarchy-emacs-setup` needs to run again.

## Improvements by priority

### High

1. **Install apheleia** (2 min): `M-x package-refresh-contents`, restart. To keep it from recurring, refresh the index before installing.

2. **Remove the pip-requirements hook** (`lang-python.el`):
   ```elisp
   (use-package pip-requirements :defer t)   ; drop the auto-complete-setup line
   ```

3. **Fix the js2 `setq-default`**: it sets `tab-width` and `indent-tabs-mode` for all buffers.
   ```elisp
   (add-hook 'js2-mode-hook (lambda () (setq-local tab-width 2)))
   ;; if wanted globally, indent-tabs-mode nil belongs in base.el
   ```

4. **Delay loading at startup** (2.0 s down to 1.65 s):
   ```elisp
   ;; lang-python.el
   (defun my-python-lsp () (require 'lsp-pyright) (lsp-deferred))
   (use-package lsp-pyright :defer t
     :hook ((python-mode python-ts-mode) . my-python-lsp))
   ;; base-extensions.el
   (use-package org-modern
     :hook ((org-mode . org-modern-mode)
            (org-agenda-finalize . org-modern-agenda)))
   ```

5. **Add `early-init.el`**: no GC pauses at startup, no flicker, faster LSP communication.
   ```elisp
   (setq gc-cons-threshold most-positive-fixnum
         read-process-output-max (* 1024 1024))
   (add-hook 'emacs-startup-hook
             (lambda () (setq gc-cons-threshold (* 32 1024 1024))))
   (push '(menu-bar-lines . 0) default-frame-alist)
   (push '(tool-bar-lines . 0) default-frame-alist)
   (push '(vertical-scroll-bars) default-frame-alist)
   (setq frame-inhibit-implied-resize t inhibit-startup-screen t)
   ```
   Optional: `(setenv "LSP_USE_PLISTS" "true")` (requires recompiling lsp-mode).

6. **Rust inlay hints and package bootstrap**:
   - Replace `lsp-rust-analyzer-server-display-inlay-hints` with `(lsp-inlay-hint-enable t)`.
   - Drop `(package-initialize)` in `base.el` (Emacs 31 activates packages before `init.el`).
   - Drop the use-package install block.
   - The advice on the private `package-vc--unpack-1` is fragile; `:vc` handles this itself in Emacs 30+.

### Medium

Other byte-compile warnings (harmless): `helm-ff-skip-boring-files` and `helm-grep-ag-*` are set before helm is loaded (better `:custom` or `with-eval-after-load`); `temp-dir` has no `defvar`; `savehist-*` is set before `require`.

## Risks

- **Indentation:** fix 3 changes indentation in non-JS buffers that silently had 2-column tabs (the default is 8).
- **Org:** with delayed loading, `org-agenda-files` and project TODOs are only set after the first Org call.
- **early-init:** `package-archives` (melpa) must still be set before any install; a permanently high GC threshold costs memory, hence the reset after startup.
- **Tree-sitter:** hooks on `python-mode`/`go-mode` do not fire in `*-ts-mode`; lsp, apheleia and gofmt would silently stop working. Grammars need a C compiler.
- **Removing cargo:** the `cargo-minor-mode` keys (`C-c C-c ...`) go away; rustic has its own.
- **Stack changes** (Helm to vertico, lsp-mode to eglot): change almost every key under `C-c h`/`C-c l` plus `docs/keybindings.md` and `CLAUDE.md`; do them as a separate step.
- **Package updates:** new MELPA snapshots can bring bugs; there is no lockfile (alternatives: `package-vc` pins or Elpaca/straight).
- **Stale `package-selected-packages`:** `M-x package-autoremove` deletes everything not listed there. Fix the list first, or apheleia/pulsar get removed.
